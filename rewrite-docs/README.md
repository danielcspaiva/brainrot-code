# BrainRot Rewrite Docs

This folder contains a plan to reimplement BrainRot from scratch with a strong UI/UX focus. It is based on the current repo state (Ink and OpenTUI code paths, PRDs in `tasks/`, and the existing feature set).

Read order:
- `rewrite-docs/feature-inventory.md` - What exists today and what it implies for a rewrite.
- `rewrite-docs/ui-ux.md` - The UX vision, flows, layout rules, and interaction model.
- `rewrite-docs/architecture.md` - Proposed system architecture and module boundaries.
- `rewrite-docs/implementation-plan.md` - Phased plan with milestones and deliverables.

If you want this collapsed into a single doc, say so and I will consolidate.
