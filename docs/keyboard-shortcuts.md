# Keyboard Shortcuts

This list reflects the OpenTUI rewrite.

## Global

- `Tab`: Switch focus between Claude and Game panes
- `?`: Toggle help overlay
- `Alt+L`: Cycle layout presets
- `Alt+Left/Right`: Resize panes
- `T`: Cycle theme
- `Esc`: Close overlay
- `Ctrl+C`: Cancel current action or quit

## Loop Controls

- `G`: Open game selector
- `S`: Open settings
- `V`: Open stats

## Task Pane

- `Up/Down` or `J/K`: Select task
- `Space`: Toggle task status
- `N`: New task
- `E`: Edit selected task
- `D`: Delete selected task

## Planning Screens

- `Enter`: Confirm / continue
- `Esc`: Back / cancel

## Overlays

- Settings: `Up/Down` to select, `Left/Right` to change, `Esc` to close
- Stats: `Left/Right` to change tabs, `Esc` to close
- Game selector: `Up/Down` to select, `Enter` to confirm, `Esc` to close

## Game Controls (Common)

- `P`: Pause / resume
- `R`: Restart
- `Q` or `Esc`: Quit game

## Game Controls (Specific)

Snake
- `Arrow keys` or `WASD`: Move

Pong
- `Up/Down` or `W/S`: Move paddle

Tetris
- `Left/Right`: Move piece
- `Up` or `W`: Rotate
- `Down` or `S`: Soft drop
- `Space`: Hard drop

Minesweeper
- `Arrow keys` or `W/S/A`: Move cursor
- `Space`: Reveal cell
- `F`: Flag/unflag
- `D`: Change difficulty
